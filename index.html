FastMailBox

About Privacy Testing terms

A native macOS and iPhone email client for personal and development testing, with explicit sending identities, local search and mailbox triage. Maintained by bmpitzen.

FastMailBox is under development. These pages provide app information for Fastmail sign-in; this site offers no app download and does not handle account credentials or OAuth callbacks.

Fastmail sign-in

The installed app opens Fastmail's authorization page in the system browser. It requests access to discover your account, read and manage mail, and use sending identities and mail submission. It also requests refresh permission when required by the server. It does not request contacts or calendars. Each device authorizes separately and keeps its grant in that device's Keychain.

Basic testing

Start with a disposable test account and synthetic mail. Connecting, reconnecting or launching can start synchronization and apply previously queued changes. Check pending work before reconnecting. Sending, mailbox changes and uploads should be deliberate test actions; opening unread mail can mark it read.

Optional coordinator and macOS Assistant Access features have separate setup and data flows. Read the privacy information and testing terms before enabling them.

Support and privacy questions

Contact the maintainer through GitHub issues. Issues are public: do not include passwords, tokens, authorization codes, private addresses, mail content or attachments.
