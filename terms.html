About Privacy Testing terms

FastMailBox is maintained by bmpitzen for personal and development testing. Use it only with accounts you own or are authorized to access, and follow your mail provider's terms.

Testing responsibly

The software is under development, and its behavior and provider compatibility are still being tested. Start with disposable test accounts and synthetic mail. Check sending identities, recipients and pending work before taking mail actions.

Connecting, reconnecting or launching can synchronize mail and apply queued changes when connectivity is available. Opening unread mail can mark it read. Sending, uploads and mailbox changes affect the provider account; perform them only when intended. Optional coordinator and assistant features require separate setup. Their data flows are described in the privacy information.

Software and distribution

This information site offers no app download and grants no public distribution license for the FastMailBox software, source code or artwork. Third-party components remain subject to their applicable terms.

Stopping a test or getting help

Remove the account locally and revoke each device's grant in Fastmail's connected-app settings when access is no longer wanted. Local removal alone does not revoke that grant. Contact the maintainer through GitHub issues; issues are public, so never include credentials or private mail.
