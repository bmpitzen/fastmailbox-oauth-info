Privacy

About Privacy Testing terms

This information describes FastMailBox's personal and development testing use. The maintainer is bmpitzen; support and privacy questions can be raised through GitHub issues. Issues are public, so do not post credentials, private mail, addresses or attachments.

Mail access and device storage

FastMailBox communicates with your selected mail provider to discover accounts and identities, synchronize mail and perform mail operations. Connecting, reconnecting or launching can begin an initial sync and process queued changes. Sending, uploading attachments and changing mailbox state communicate with the provider.

The app stores its mail cache, downloaded attachments, drafts and search indexes on the device. Credentials are kept in the device Keychain and are not synchronized between devices; each device connects separately. The reader uses inert plain text and blocks remote resources. Attachments download following user action. The optional sentence model for search runs on the device and is off by default.

Optional services

A separately configured coordinator is intended to perform scheduled operations while devices are asleep. Depending on enabled features, it can receive provider credentials, scheduling and account identifiers, device/push information and opted-in shared rule metadata. Native Fastmail OAuth grants are not supported for coordinator enrollment and are not transferred to it.

Assistant Access on macOS is off by default. If enabled through an owner's authenticated proxy, a connected cloud assistant can request cached mail and selected extracted attachment text. Requested content leaves the device for the proxy and assistant service. A separate toggle enables reversible triage and local draft creation; these tools cannot send mail or permanently delete it. The app does not itself call a cloud model. Review the services you choose before connecting them.

Removing access

Remove Account removes the app's local account data and credentials. It does not revoke provider-side access or erase copies already received by other services or kept in backups. Revoke each device's Fastmail OAuth grant separately in Fastmail's connected-app settings; delete its API token there if using the development token route. Optional coordinator, proxy and assistant access require separate disconnection and cleanup.

This website

This static information site is hosted on GitHub Pages. It contains no analytics, scripts or forms and uses a locally hosted logo. GitHub can process ordinary request information, such as network addresses and request logs. Loading the logo during authorization can also disclose a request's timing to the host. Provider authorization pages and optional services have their own privacy practices.
